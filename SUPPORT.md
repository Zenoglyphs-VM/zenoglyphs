# Legacy status and support

The organization's repository description marks Zenoglyphs deprecated. This
repository retains the original `zcribe` inscriptions implementation, its
embedded viewer, specifications, deployment examples and historical evidence.
Deprecation and GitHub archival are separate: the repository was not archived
when public metadata was reviewed on 2026-10-25.

## Version and maintenance status

No published GitHub releases or tags were observed in that snapshot. A source
commit, committed binary asset or passing CI job is not a signed, supported
distribution. This review establishes no supported-version window, response
cadence, ongoing maintenance service or commitment to repair every historical
finding. Those decisions require an explicit maintainer statement.

The [security policy](SECURITY.md) still provides the private reporting guidance
and the original mainnet/devnet scope. Deprecation does not turn a confidential
finding into an ordinary public issue. If private reporting is unavailable,
retain details privately while a verified contact is established.

For a non-sensitive source or documentation question, use the affected
repository's available issue flow. Include the exact revision and a small owned
example in English. Omit personal identities, workstation paths, credentials,
wallet/signing material, account inventories and raw operator diagnostics.
This document does not establish a new support contact or response deadline.

## Project direction and migration

The separately maintained ZVM repositories describe a based EVM architecture.
The [migration scope](docs/MIGRATION.md) points to exact reviewed sources and
explains the distinction from this legacy inscriptions implementation. A shared
organization or project name does not establish database, asset, wallet or
protocol compatibility. No migration was executed or qualified for this change.

Use the [source and distribution record](docs/PROVENANCE.md) to identify retained
history, license notices and build boundaries. Any future support-policy change,
release, deployment, migration execution or repository archival requires its
own authorized maintainer/operator decision.
